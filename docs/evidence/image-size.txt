The 95.4 MB install layer is 72.9 MB of @prisma/client/runtime (source maps plus
wasm-base64 builds for every database provider) and ~22 MB of fastify/zod.
It is the largest remaining removable block, but it is the runtime the app
actually uses.

## why not 120 MB

node:22-alpine is 168 MB before a byte of application code (the node binary is
130 MB, npm 17 MB, yarn 5 MB). Prisma itself is not the blocker: the generated
engine in the image is libquery_engine-linux-musl-openssl-3.0.x.so.node, which
runs, and /ready answered 200 against a real PostgreSQL 16 container. The
120 MB target is below the floor of this base image; it would need a different
base (e.g. a distroless/chiselled node) and would still have to carry ~93 MB of
Prisma-driven npm dependencies. 284 MB is the measured result and meets the
≤ 300 MB fallback.
